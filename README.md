# Website Studio: website concepts

Restaurant and business website concepts by Website Studio.

**View them live:** https://kaushikandinakaran.github.io/websites/

## What is inside

- **Four Indo-Nepali restaurant designs**: a classic warm kitchen, a fast-order momo bar, an elegant reservation-first dining room, and a tea house with family-feast ordering.
- **Nine more restaurant styles**: steakhouse, bakery, taverna, tea and dim sum, sushi, pizza, bistro, Mexican and brunch.
- **Five editorial sites**: fine dining, a spa, a gym, an architecture studio and a technology consultancy.
- **Laptop, tablet and phone preview**: every card on the home page opens the design in a device frame, so you can see exactly how it looks on a phone.

Each restaurant concept has a menu with photos, a cart with a visible total, a short checkout (pickup or delivery) and a table-booking form. Checkout is a demonstration: no payment is taken and no order is sent.

## View it on your computer

Needs Python 3.9 or newer.

```
python showcase-v2/serve.py 8810
```

Then open http://localhost:8810/ in a browser.
