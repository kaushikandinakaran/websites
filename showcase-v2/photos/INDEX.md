# Photo library index

Real stock photographs for the 10 Showcase V2 sample sites. All from **Pexels** under the Pexels License (free commercial use, no attribution required; credits kept anyway in `CREDITS.md`). They are NOT the client's food: label as stock in every site.

Each base name has three files: `<base>-1600.webp` (1600 px wide; portrait images are capped at 2000 px tall, so their "1600" file is narrower, see size column), `<base>-800.webp` and `<base>-400.webp` (same aspect ratio, for `srcset`). Size column = pixel size of the `-1600` file.

Roles: **hero** (wide banner candidate), **interior** (room or table setting), **hands** (chef/hands/kitchen action), **dish** (one menu item).
